# Dijo Pro v7

نسخه حرفه‌ای‌تر نرم‌افزار مدیریت کسب‌وکار دیجو، مناسب اجرای محلی با Pydroid 3 و Flask.

## ورود آزمایشی
- نام کاربری: `admin`
- رمز عبور: `1234`

## امکانات v7
- فاکتور حرفه‌ای و صفحه چاپ / ذخیره PDF از مرورگر
- سبد فروش سریع با جستجوی نام، کد و بارکد
- API جستجوی محصول برای فروش سریع
- مرجوعی جزئی فاکتور و برگشت خودکار موجودی
- دفتر پرداخت مشتری و تأمین‌کننده
- صفحه مدیریت بدهی‌ها
- مدیریت کاربران و نقش‌ها: مدیر، فروشنده، انباردار، حسابدار
- گزارش‌های بازه‌ای، روند فروش و سودآورترین محصولات
- پشتیبان‌گیری و بازیابی دیتابیس با پشتیبان خودکار قبل از Restore
- اعلان هوشمند برای موجودی کم، وظایف سررسیدشده و بدهی‌ها
- اتصال Groq / چت دیجو از طریق تنظیمات
- رابط RTL فارسی و ریسپانسیو

## اجرا
```bash
pip install -r requirements.txt
python app.py
```
سرویس روی پورت `8000` اجرا می‌شود.

> برای امنیت، کلید Groq و `DIJO_SECRET_KEY` را در محیط اجرا تنظیم کنید. اگر پروژه را عمومی می‌کنید، کلید API فعلی را حتماً در پنل Groq تعویض/لغو کنید.
